Política de privacidade

Inbox Zero Rafael Brion — atualizada em 28/10/2026

Quem usa

Este aplicativo é uma ferramenta pessoal, usada somente por Rafael Brion na própria conta Google. Não é oferecido a outras pessoas.

Quais dados acessa

Com a autorização do titular, o aplicativo acessa pela API do Gmail as mensagens, os marcadores e as configurações básicas da conta do próprio Rafael, além do nome e do e-mail do perfil Google.

Como os dados são usados

Os dados servem apenas para organizar a caixa de entrada do titular: classificar mensagens, aplicar marcadores, arquivar e preparar rascunhos de resposta. O conteúdo das mensagens é enviado ao modelo de IA Claude, da Anthropic, somente para essa análise.

Onde ficam guardados

O aplicativo roda no computador do titular. O banco de dados e as credenciais de acesso ficam nesse computador. Nenhum dado é vendido, compartilhado ou usado para publicidade.

Uso Limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
